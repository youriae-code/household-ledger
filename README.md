# 나의 가계부

회원가입 없이 쓰는 간단한 가계부입니다. `index.html` 파일 하나로 동작하고, 데이터는 [Supabase](https://supabase.com) DB에 저장됩니다.

## 기능

- 수입/지출 내역 추가·삭제, 월별 보기
- **고정/변동 구분**: 월급은 고정 수입, 나머지는 변동 수입 / 지출은 분류에 따라 고정비·변동비로 자동 분류
- **당기 순이익**(수입 − 지출)과 저축률 표시, 손익 요약 표
- 지출 **결제 방식(카드/현금)** 표시 및 비율 분석
- 분류별 지출 그래프
- CSV 내보내기, JSON 백업·불러오기
- 다크 모드, 모바일 화면 지원

## 사용법

`index.html`을 브라우저(Chrome, Edge 등)로 열면 됩니다.

## 데이터 저장

- 모든 내역은 Supabase의 `entries` 테이블에 저장되어, 어느 기기에서 열어도 같은 내역이 보입니다.
- **하나의 공유 가계부**입니다. 사이트 주소를 아는 사람은 누구나 내역을 보고, 추가하고, 삭제할 수 있으니 민감한 정보는 넣지 마세요.
- 코드에 들어 있는 키는 브라우저 공개용 `publishable` 키입니다. 테이블 접근은 행 수준 보안(RLS) 정책으로 조회·추가·삭제만 허용합니다.
- 예전 버전에서 브라우저(localStorage)에 저장한 내역이 있으면, 처음 열 때 DB로 옮길지 물어봅니다.
