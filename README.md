# 나의 가계부

서버·DB·회원가입 없이 브라우저에서 바로 쓰는 간단한 가계부입니다. `index.html` 파일 하나로 동작합니다.

## 기능

- 수입/지출 내역 추가·삭제, 월별 보기
- **고정/변동 구분**: 월급은 고정 수입, 나머지는 변동 수입 / 지출은 분류에 따라 고정비·변동비로 자동 분류
- **당기 순이익**(수입 − 지출)과 저축률 표시, 손익 요약 표
- 지출 **결제 방식(카드/현금)** 표시 및 비율 분석
- 분류별 지출 그래프
- CSV 내보내기, JSON 백업·복원
- 다크 모드, 모바일 화면 지원

## 사용법

`index.html`을 브라우저(Chrome, Edge 등)로 열면 됩니다.

데이터는 브라우저의 localStorage에 저장되므로 같은 브라우저에서만 보이고, 브라우저 데이터를 지우면 사라집니다. 중요한 데이터는 **백업** 버튼으로 JSON 파일을 저장해 두세요.
